🚀 Guía Paso a Paso para Desplegar FutBolPredict AI en GitHub PagesSigue estas instrucciones sencillas para subir tus archivos a GitHub y hacer que tu aplicación web sea pública para cualquier persona con acceso a internet.Paso 1: Guardar los Archivos en tu ComputadoraEn el panel de la derecha de este chat, descarga o copia el código del archivo index.html.Guarda el archivo en tu computadora con el nombre exacto: index.html.(Opcional) Copia el texto del archivo README.md y guárdalo en la misma carpeta con el nombre README.md.Paso 2: Crear una Cuenta y un Nuevo Repositorio en GitHubEntra a https://github.com/ e inicia sesión (si no tienes cuenta, haz clic en Sign up para registrarte gratis).En la esquina superior derecha, haz clic en el botón con el ícono + y selecciona "New repository" (Nuevo repositorio).Completa los siguientes campos:Repository name: Escribe un nombre para tu proyecto (por ejemplo: futbolpredict-ai).Description: (Opcional) Dashboard de predicción de marcadores exactos.Public / Private: Asegúrate de seleccionar Public (debe ser público para usar GitHub Pages gratis).NO marques las casillas de "Add a README file" ni "Add .gitignore".Haz clic en el botón verde al final que dice "Create repository".Paso 3: Subir los Archivos a GitHubEn la pantalla que aparece tras crear el repositorio, busca el enlace que dice "uploading an existing file" (subir un archivo existente).Se abrirá una ventana de carga. Arrastra y suelta tus archivos index.html y README.md desde tu computadora hacia esa ventana (o haz clic en choose your files para buscarlos).En la parte inferior, en el campo que dice Commit changes, puedes dejar el texto por defecto o escribir "Primer commit".Haz clic en el botón verde "Commit changes".Paso 4: Activar GitHub Pages (Publicar la Web Gratis)Dentro de tu repositorio recién creado, ve a la pestaña ⚙️ Settings (Configuración), ubicada en el menú horizontal superior.En el menú lateral izquierdo, busca y haz clic en la sección Pages (dentro del apartado Code and automation).En la sección Build and deployment:Bajo el menú desplegable Branch, cambia None a main (o master).Deja la carpeta en / (root).Haz clic en el botón Save (Guardar).Paso 5: Abrir tu Sitio Web en VivoEspera entre 1 y 3 minutos mientras GitHub compila tu sitio.Recarga la página de Settings > Pages.Verás un recuadro verde arriba que dice:"Your site is live at https://tu-usuario.github.io/futbolpredict-ai/"Haz clic en ese enlace y ¡listo! Tu Dashboard de Predicción estará funcionando en internet.💡 Consejos útiles¿Cómo actualizar tu web más adelante? Si realizas cambios en tu archivo index.html, simplemente entra a tu repositorio en GitHub, haz clic en index.html, luego en el ícono del lápiz (Editar) o sube el nuevo archivo reemplazando el anterior.API Key: Cuando compartas la URL de tu página con otras personas, cada usuario podrá usar el modo simulación o ingresar su propia clave de API en el botón 🔑 Configurar API.
